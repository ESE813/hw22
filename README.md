# Приложение для интернет-магазина

## Использование

1. Создан Django-проект.
2. Создано приложение catalog и зарегистрировано в INSTALLED_APPS.
3. Настроена маршрутизация для данного приложения.
4. Оптимизированы два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
5. К данным HTML-шаблонам подключены стили Bootsrap.
6. Создан контроллер для отображения домашней страницы.
7. Создан контроллер для отображения страницы с контактной информацией.
8. Настроена маршрутизация для этих контроллеров.
